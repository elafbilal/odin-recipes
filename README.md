Odin Recipes

This is my first project from The Odin Project Foundations course.

About the Project

Odin Recipes is a basic recipe website built using HTML. The project focuses on creating webpages, organizing content, and linking multiple pages together.

Skills Demonstrated

By completing this project, I will demonstrate my understanding of:

* HTML boilerplate and document structure
* Headings and paragraphs
* Ordered and unordered lists
* Links and images
* Relative file paths
* Organizing files and directories

Project Goals

Build a simple recipe website with a homepage that links to individual recipe pages.
